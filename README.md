# Hydropulse

Hydropulse is a platform for monitoring water levels and soil moisture, with automated alerts when moisture drops below a set threshold or water-system conditions need attention.

## What it does

- Monitors water and moisture readings from connected sensors.
- Tracks moisture levels over time so users can spot changes.
- Sends automated alerts when readings fall below configured thresholds.
- Helps users respond to irrigation needs, low water levels, and sensor or system issues.
